### ☕ [Coffee Lab](https://github.com/vaoliverosdev/coffeeLab)

Meu principal projeto autoral: uma aplicação web completa para **gerenciar, explorar e registrar cafés especiais**.

O projeto reúne autenticação, banco de dados, estoque, receitas, extrações, diário sensorial, estatísticas, PWA com recursos offline e um **Barista de IA** integrado via API.
